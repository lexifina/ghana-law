# 2. Address of Agent of Foreign Power.
Any address, whether within or without Ghana, reasonably suspected of being an address used for the receipt of communications intended for an agent of a foreign power, or any address at which such an agent resides, or to which he resorts for the purpose of giving or receiving communications, or at which he carries on any business, shall be deemed to be the address of an agent of a foreign power, and communications addressed to the address to be communications with the agent.

# 4. Instruments, Except Wills, to Describe the Land Affected.
No instrument, except a will or probate, shall be registered unless it contains a description (which may be by reference to a plan) which, in the opinion of the registrar, is sufficient to enable the location and boundaries of the land to which it relates to be identified or a sufficient reference to the date and particulars of registration of an instrument affecting the same land and already registered.
